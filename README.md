# AOSStudio NDK

AOSStudio NDK provides a source-built C and C++ toolchain for Linux x86-64 hosts. The first package follows revision `28.2.13676358` (r28c) and supplies Clang, LLD, Android sysroots and target runtimes for CMake and ndk-build.

[LICENSE](LICENSE) covers this repository's code and verification fixtures. The toolchain and sysroot retain their upstream licenses and notices.
